# 猹杀游戏规则与新手入门

猹杀是一款隐藏身份、通过发言和投票找出狼人的游戏。你扮演一名玩家，其余座位由 AI 控制；角色配置随人数变化，不是每局都有全部角色。

## 阵营与胜负

- **好人阵营**：村民，以及预言家、女巫、猎人、守卫、白痴等神职。所有狼人出局，好人获胜。
- **狼人阵营**：狼人和白狼王。当前实现中，存活狼人数量达到或超过存活好人数量时，狼人获胜。

本项目目前采用上述人数判定，并非部分线下玩法中的“屠边”（杀光全部村民或全部神职）。特殊技能结算时按游戏流程检查胜负。

## 一局怎么进行

1. **查看身份**：确认自己的阵营和技能。别人发言中声称的身份可能是伪装。
2. **夜间行动**：狼人选择击杀目标，有夜间技能的角色按主持人提示行动。你只能使用自己身份允许的技能。
3. **白天讨论**：根据死亡公告、此前发言和投票记录判断。轮到你时说明怀疑谁、理由是什么，再结束发言。
4. **放逐投票**：选择本轮可投的玩家，得票最多者被放逐；平票按界面提示进入 PK 或后续结算。警徽选举与放逐投票是不同环节。
5. **继续下一轮**：处理遗言、开枪、警徽移交等事件后继续，直到一方获胜。

## 角色速查

| 角色 | 能做什么 |
| --- | --- |
| 村民 | 没有夜间技能，通过发言和投票找狼人。 |
| 狼人 | 知道狼队友，夜间参与选择击杀目标，白天可以隐藏身份。 |
| 白狼王 | 属于狼人阵营，还可在白天自爆带走一人。 |
| 预言家 | 每晚查验一人的好人或狼人阵营。 |
| 女巫 | 有一瓶解药和一瓶毒药，具体可用行动以当晚界面为准。 |
| 猎人 | 死亡后符合条件时可开枪带走一人；被毒死不能开枪。 |
| 守卫 | 每晚保护一人，可以自守，但不能连续两晚守同一人。 |
| 白痴 | 首次被投票放逐时翻牌免死，之后失去投票权。 |

警长不是独立角色。警长在放逐投票中有 1.5 票，死亡时可移交警徽。拿到警徽不代表身份已被证实。

## 常见术语

- **上警／警上**：报名竞选警长／警长竞选发言阶段。
- **跳身份／对跳**：声称自己是某角色／不同玩家声称同一个角色。
- **金水／查杀**：预言家声称查验为好人／狼人；公开发言可能真假混杂。
- **归票**：建议大家集中投某个目标，不是强制指令。
- **平安夜**：当夜无人出局，不直接证明是哪项技能生效。

刚开始不必记住所有术语。先记“谁声称什么、谁支持谁、实际投了谁”，再对照下一轮信息。玩家出局后，其公开发言和投票仍有推理价值。
