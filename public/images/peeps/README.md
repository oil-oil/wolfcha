# Crowd illustration

`all-peeps.png` is the 15 × 7 sprite sheet used by [Skiper UI 39](https://skiper-ui.com/v1/skiper39), downloaded from `https://skiper-ui.com/images/peeps/all-peeps.png`.

- Illustration: [Open Peeps](https://www.openpeeps.com/), by Pablo Stanley.
- Animation reference: [Crowd Simulator](https://codepen.io/zadvorsky/pen/xxwbBQV), by Zadvorsky.
- React implementation reference: Skiper UI / Gurvinder Singh.
