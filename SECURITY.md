# Security Policy

## Reporting Security Issues

If you discover a security vulnerability, report it through
[GitHub private vulnerability reporting](https://github.com/oil-oil/wolfcha/security/advisories/new).
Please do not open a public issue for an undisclosed vulnerability.

Please include:
- Description of the issue
- Steps to reproduce
- Potential impact

## What to Expect

We will acknowledge the report as soon as practical, investigate it, and coordinate disclosure
with the reporter before publishing details.

## Supported Versions

Only the latest GitHub release is actively supported with security fixes.
